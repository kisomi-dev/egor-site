# Egor — personal site

Одностраничный сайт-визитка: B2B-продажи, ИИ-ассистенты и сайты для бизнеса.

## Стек

- Чистый HTML / CSS / JavaScript — без сборки и зависимостей
- Двуязычность RU / EN с сохранением выбора в `localStorage`
- Анимации: появление при скролле, подсветка за курсором, aurora-фон
- Адаптив + поддержка `prefers-reduced-motion`

## Локальный запуск

Просто открыть `index.html` в браузере.

Или поднять локальный сервер:

```powershell
npx serve .
```

## Структура

```
egor-site/
├── index.html    — разметка и контент
├── styles.css    — оформление и анимации
├── script.js     — переводы, анимации, интерактив
└── favicon.svg   — иконка сайта
```
